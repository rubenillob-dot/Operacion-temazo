# Operacion-temazo
Panel interactivo para la valoración de canciones de la gala Operación Temazo 1. Incluye sistema de puntuación automática, gestión de pases de oro y letras de canciones

# 🎤 Operación Temazo 1 - Panel de Rubenillo:

Panel interactivo desarrollado para la gestión de la primera fase de **Operación Temazo**. Este sistema permite al jurado y al público valorar las canciones en tiempo real.

## ✨ Características
- 🎵 **15 bloques de canciones** listos para configurar.
- 🎫 **Sistema de Pase de Oro** visual para canciones seleccionadas.
- 🧮 **Cálculo automático de notas**: 50% Jurado (Ari), 25% Jurado (Luismi) y 25% Público.
- 📖 **Letras integradas** mediante ventanas modales.
- 📱 **Diseño Responsivo** adaptable a diferentes pantallas.

## 🛠️ Tecnologías utilizadas
- HTML5 / CSS3 (Grid & Flexbox)
- JavaScript Vanilla (Lógica de puntuación y UI)
- FontAwesome para la iconografía

## 🚀 Instalación
Solo necesitas clonar el repositorio y abrir `index.html` en tu navegador.
