# Operacion-temazo

Panel interactivo para la valoración de canciones de la gala Operación Temazo 1. Incluye sistema de puntuación automática, gestión de pases de oro, fase final tipo torneo y reproductor de audio integrado.

## 🎤 Operación Temazo 1 - Panel de Rubenillo:

Panel interactivo desarrollado para la gestión completa de **Operación Temazo**. Este sistema permite al jurado valorar las canciones en tiempo real y genera automáticamente los cruces eliminatorios para decidir al ganador absoluto.

### ✨ Características

* **🎵 15 bloques de canciones:** Equipados con reproductor de audio integrado, barra de progreso interactiva (clic para avanzar/retroceder) y control de volumen general.
* **🎫 Sistema de Pase de Oro:** Botón visual que otorga prioridad absoluta para clasificar a la fase final, ignorando la puntuación matemática.
* **📊 Cálculo automático de notas:** Fórmula ajustada al **50% Ari y 50% Luismi** para la clasificación automática.
* **🏆 Fase Final (Brackets):** Generación dinámica de un cuadro de torneo tipo eliminatoria que selecciona automáticamente a las 8 mejores canciones (Top notas + Pases de oro).
* **⚔️ Batallas 1vs1:** Ventana modal interactiva para enfrentar a dos canciones, con mini-reproductores integrados para escuchar fragmentos antes de decidir quién avanza de ronda.
* **🥇 Pantalla de Campeón:** Modal épico dedicado a la canción ganadora absoluta con reproducción automática.
* **🎬 Animaciones y efectos:** Efectos visuales de aparición lenta, destellos y sonidos especiales (redoble de tambores, efecto de revelación) para darle un toque televisivo al stream.
* **📖 Letras integradas:** Visualización de la letra de cada participante mediante ventanas modales.
* **📱 Diseño Responsivo:** Estructura adaptable a diferentes tamaños de pantalla usando Flexbox y CSS Grid.

### 🛠️ Tecnologías utilizadas

* HTML5 / CSS3 (Grid & Flexbox)
* JavaScript Vanilla (Lógica de puntuación, generación de torneo, control de DOM y reproductor de audio)
* FontAwesome para la iconografía
